  1. Outer
    Network isolation

    All styles and scripts are embedded in the page. Nothing loads from outside, so the firewall has nothing to block.

  2. Layer 2
    Identity check

    Each link carries a personal ID that must match the logged-in work email. A forwarded link opens an "unauthorized" page.

  3. Layer 3
    Anti-double-submit

    Checked three times: when the page loads, when Submit is clicked, and on the server right before the answer is written.

  4. Inner
    XSS sanitizer

    All text is escaped before it's displayed, so code typed into a comment shows as plain text and never runs.

Speed

Beating the 6-minute clock

Apps Script stops any job after 6 minutes. To build the dashboard, every survey answer has to be matched to its employee record, about ~3,500 answers against 4,000+ employee records. How you search decides whether that finishes in time.

From a number to a reason

I didn't just build a dashboard. I gave management a way to investigate: find where engagement is weakest, see why, and hear it from the people involved.

In the real survey3 regions scored below 60% on Respect & Recognition and Leaders. Their comments gave management an early read on why, before deciding where to act.
